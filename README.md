# DESAIN
program terdiri dari 3 class, yaitu **Film**, **FilmBioskop**, dan **FilmTayang**. Program ini menerapkan multilevel inheritance yang terdiri dari **Film** menjadi class dasar, lalu **FilmBioskop**, lalu terakhir **FilmTayang** sebagai turunan class paling bawah. Susunan inheritance tersebut dipilih sebab **Film** merupakan class yang paling luas(umum) diikuti **FilmBioskop** dan **FilmTayang** menjadi rincian dari class **Film**. Berikut atribut dari masing-masing class:
* Film:
  * ID
  * judul
  * genre
* FilmBioskop:
  * Durasi
  * Studio
  * KlasifikasiUsia
* FilmTayang:
  * HargaTiket
  * JamTayang
  * StatusTayang
